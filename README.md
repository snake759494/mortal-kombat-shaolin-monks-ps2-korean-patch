# 모탈 컴뱃: 샤오린 몽크스 PS2 한글패치

PS2 북미판 **Mortal Kombat: Shaolin Monks (SLUS-21087)**용 비공식 한국어 패치입니다. 메뉴, 일시정지 화면, 기술 목록, 튜토리얼, HUD, 메모리 카드 안내 같은 게임 안 텍스트를 한국어로 바꿨습니다. **오프닝·엔딩 등 동영상 6편에는 한국어 자막**을 넣었고, 메인 메뉴 그림 글자도 한글로 다시 그렸습니다. PCSX2용 **16:9 와이드 패치**도 함께 배포합니다. 현재 배포판은 **v1.0 (2026-11-02)**입니다.

[패치 다운로드](https://github.com/snake759494/mortal-kombat-shaolin-monks-ps2-korean-patch/releases/latest) · [기술 설명](docs/TECHNICAL.md) · [재빌드](docs/BUILD.md) · [변경 기록](CHANGELOG.md) · [권리 안내](RIGHTS.md)

릴리즈 첨부 파일은 한글패치 **Mortal_Kombat_Shaolin_Monks_KO_v1.0.xdelta**와 와이드 패치 **SLUS-21087_0FFD59AD.pnach**입니다. 저장소에는 제작 소스, 번역, 검증 자료만 공개합니다. 원본 디스크 이미지와 완성된 디스크 이미지, 추출한 게임 파일, 글꼴 파일, 외부 실행 파일은 포함하지 않습니다. GitHub가 자동으로 만드는 Source code ZIP/TAR는 저장소 소스를 압축한 것이며 게임 파일이 아닙니다.

## 게임 소개 및 대상 버전

「Mortal Kombat: Shaolin Monks」는 Midway가 2005년에 낸 3D 벨트스크롤 액션 게임입니다. 『모탈 컴뱃 2』 시기를 배경으로, 샤오린 무승 리우 캉과 쿵 라오가 아웃월드로 들어가 샹 쭝과 샤오 칸의 군대에 맞섭니다. 2인 협력 플레이를 지원하며, 음성은 영어입니다.

이 패치는 **PS2 북미판 SLUS-21087의 DVD 이미지(ISO)**에만 적용됩니다. 파일 이름보다 아래 표의 크기와 해시가 일치하는지가 중요합니다.

## 패치 적용 방법

### Windows에서 원본 확인

```powershell
Get-FileHash -Algorithm MD5 -LiteralPath '.\Mortal Kombat - Shaolin Monks (USA).iso'
```

위 표와 다르면 적용을 중단하세요. CHD, CSO, 압축 이미지에는 적용할 수 없습니다.

### xdelta UI 사용

1. 릴리즈에서 `Mortal_Kombat_Shaolin_Monks_KO_v1.0.xdelta`를 받습니다.
2. xdelta3 패치를 지원하는 도구에서 **Apply Patch** 기능을 엽니다.
3. **Patch**에는 xdelta 파일을, **Source File**에는 해시가 일치하는 원본 `.iso`를 선택합니다.
4. **Output File**에는 새 파일 이름을 지정합니다(예: `Mortal Kombat - Shaolin Monks (USA) [Korean].iso`).

xdelta는 호환성을 위해 압축 없이(`-e -0`) 만들었습니다. 동영상 영상 데이터를 다시 인코딩했기 때문에 xdelta 크기가 약 560MB입니다. xdelta 자체는 [공식 프로젝트](https://github.com/jmacd/xdelta)를 참고하세요.

### 명령줄 사용

```powershell
.\xdelta3.exe -d -s '.\Mortal Kombat - Shaolin Monks (USA).iso' '.\Mortal_Kombat_Shaolin_Monks_KO_v1.0.xdelta' '.\Mortal Kombat - Shaolin Monks (USA) [Korean].iso'
```

해시를 자동으로 검사하는 도구도 있습니다. Python 3과 xdelta3가 필요하며, 같은 이름의 출력 파일이 이미 있으면 덮어쓰지 않습니다.

```powershell
python tools/apply_release.py --xdelta '.\xdelta3.exe' --source '.\Mortal Kombat - Shaolin Monks (USA).iso' --patch '.\Mortal_Kombat_Shaolin_Monks_KO_v1.0.xdelta' --output '.\Mortal Kombat - Shaolin Monks (USA) [Korean].iso'
```

### PCSX2에서 실행

새 ISO를 열면 됩니다. 게임 ID는 원본과 같아 메모리 카드 세이브는 원본판과 공유됩니다. 원본판에서 만든 세이브 스테이트는 쓰지 마세요(실행파일이 바뀌어 맞지 않습니다).

## 16:9 와이드 패치 (PCSX2)

PCSX2 공식 패치 데이터베이스([pcsx2_patches](https://github.com/PCSX2/pcsx2_patches))에 이 게임의 16:9 패치(`SLUS-21087_455DD546.pnach`)가 있습니다. 그런데 한글패치는 한글 출력 코드를 넣으려고 실행파일(`SLUS_210.87`)을 고쳤기 때문에, **한글판의 게임 CRC는 `0FFD59AD`로 바뀌어** 내장 패치가 적용되지 않습니다. 패치가 고치는 네 곳(화면비 값, 검은 테두리 수정, 동영상 비율 수정 2곳)은 한글판에서도 원래 값이 그대로임을 확인하고, 같은 내용을 한글판 CRC 이름으로 만든 파일을 배포합니다.

| 파일 | 대상 | 게임 CRC | 항목 |
| --- | --- | --- | --- |
| `SLUS-21087_0FFD59AD.pnach` (릴리즈 첨부) | 한글판 v1.0 | `0FFD59AD` | Widescreen 16:9 (PCSX2 공식 패치 내용 그대로) |

원본 북미판(영문, CRC `455DD546`)은 PCSX2 v2.x에 내장된 와이드 패치를 그대로 쓰면 되므로 이 파일이 필요 없습니다.

**한글패치 새 버전이 나오면 와이드 패치도 같은 릴리즈에 함께 첨부합니다. 실행파일이 바뀌면 CRC도 바뀌므로 항상 같은 릴리즈의 pnach를 쓰세요.**

### 설치 (PCSX2 v2.x)

1. 릴리즈에서 `SLUS-21087_0FFD59AD.pnach`를 받습니다. 파일 이름을 바꾸지 마세요(PCSX2는 이름의 CRC로 게임을 찾습니다).
2. PCSX2 `patches` 폴더에 넣습니다.
   - 설치판: `문서\PCSX2\patches\`
   - 휴대용판: `pcsx2-qt.exe`가 있는 폴더의 `patches\`
   - 폴더 위치는 **설정 → 폴더**에서도 확인할 수 있습니다.
3. 게임 목록에서 한글판 ISO를 오른쪽 클릭 → **속성** → **패치** 탭을 엽니다.
4. **Widescreen 16:9** 항목에 체크합니다. 화면비는 패치가 자동으로 16:9로 바꿉니다(`gsaspectratio=16:9`).
5. 게임을 실행하면 화면에 "게임 패치 1개 활성화" 같은 알림이 나옵니다. 이미 실행 중이었다면 게임을 새로 부팅하세요.

### 끄기·문제 해결

- 끄려면 4번의 체크를 해제합니다.
- 패치 탭에 Widescreen 16:9 항목이 보이지 않으면 파일 위치나 이름이 틀린 것입니다. 게임을 실행한 뒤 **도구 → 로그 표시**에서 `CRC:` 줄이 `0FFD59AD`인지 확인하세요. `455DD546`이면 한글패치가 적용되지 않은 원본입니다.
- 화면이 여전히 4:3이면 **설정 → 그래픽 → 화면비**를 16:9로 바꾸세요.
- PCSX2 1.6 이하에서는 `cheats_ws` 폴더에 넣고 **와이드스크린 패치 사용**을 켜세요. 이 경우 `[Widescreen 16:9]` 줄을 지워야 할 수 있습니다.

### 알려진 한계

- 한글판에서 패치 값이 메모리에 들어가는 것은 확인했지만, 3D 게임 화면을 16:9로 직접 비교하지는 못했습니다. 화면 끝 잘림이나 늘어짐이 보이면 이슈로 알려 주세요.
- 실기(PS2 본체)에서는 쓸 수 없습니다.

### 번역 원칙

- 기계 번역 없이 문맥을 보고 직접 번역했습니다. 동영상 영어 대사는 로컬 음성 인식(Whisper)으로 받아쓰기만 하고 번역은 직접 했습니다.
- 캐릭터 이름은 국내에서 통용되는 표기를 따랐습니다(리우 캉, 쿵 라오, 라이덴, 샹 쭝, 샤오 칸 등).
- 페이탈리티·브루탈리티 등 시리즈 고유 용어는 음역했습니다.

### 번역하지 않은 것

- 음성(영어). 게임 엔진으로 실시간 재생되는 컷신은 원래 자막 기능이 없어 자막을 넣지 못했습니다.
- 동영상 안의 기합 소리, 받아쓰기가 불확실한 짧은 외침
- 타이틀 로고, 제작사 로고, 저작권 표기
- 일부 개발용 자리표시 문구(PH)

## 알려진 한계

- 모든 화면을 직접 확인하지는 못했습니다. 후반 스테이지 안내와 해금 요소 설명 일부는 에뮬레이터 화면으로 보지 못했습니다. 칸을 넘치거나 어긋난 문구가 있으면 이슈로 알려 주세요.
- 동영상은 오프닝만 에뮬레이터에서 재생해 확인했고, 나머지 5편은 인코딩 결과 미리보기로 확인했습니다.
- 인게임 확인은 PCSX2 v2.x로 했습니다. 실기에서의 동작은 확인하지 못했습니다.
