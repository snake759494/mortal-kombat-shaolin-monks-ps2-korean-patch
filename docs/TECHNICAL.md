# 기술 설명

## 디스크 구성

- 실행파일 `SLUS_210.87`, 게임 데이터 `GAMEDATA.WAD`(~`.WAJ`, PWF 목차 + EWDF raw-deflate 압축, `tools/wadlib.py`), 동영상 `/FRONT/MOVIES/*.SFD`.
- 게임은 파일을 `GAMEDATA.WAD` 기준 `(LBA 차이)×2048` 오프셋으로 찾고, 오프셋이 `0x19000000`을 넘으면 다음 WAD 번호로 해석합니다. 그래서 `GAMEDATA.WAD`를 이미지 끝으로 옮기고 크기가 바뀐 파일을 그 바로 뒤에 덧붙여 이 범위 안에 둡니다. 실행파일과 동영상은 제자리에 덮어씁니다. ISO9660 레코드와 UDF File Entry를 함께 고칩니다(`tools/isowrite.py`, `tools/udf.py`). IOP 리소스 로더가 UDF로 파일을 찾기 때문입니다.

## 한글 출력

원래 글꼴 엔진은 1바이트 글자를 맵 표로 글리프 번호(0~0xFF)에 대응시키고, 고정된 폰트 텍스처(VRAM)에서 UV를 읽어 그립니다.

1. **인코딩**: 한글은 리드(A1–FE)+트레일(A1–FE) 2바이트, 번호 `k = (리드-A1)*94 + (트레일-A1)`.
2. **디코더** `tools/kdec.S`: 원래 글자 읽기 함수(0x37fb90 / 0x37fc30)를 대체합니다. 한글이면 글리프 슬롯 0xF0–0xFE를 돌려 쓰며, 슬롯의 UV·폭을 캐시 칸에 맞게 고칩니다. 1바이트 글자 동작(소문자 접기, 공백 처리, 맵 조회)은 그대로입니다.
3. **글리프 캐시** `tools/kcache.c`: 폰트 텍스처 아래쪽을 캐시 칸으로 나누고 LRU로 한글 음절을 배치합니다. 칸이 바뀌면 RAM의 캐시 영상에 글리프를 복사하고, 그 행 띠를 GIF DMA로 텍스처 VRAM에 직접 올린 뒤 TEXFLUSH 합니다.
4. **코드 배치** `tools/elfpatch.py`: 디코더·캐시·글리프 비트맵을 0xA0000 PT_LOAD 세그먼트로 실행파일에 붙이고 호출부 10곳을 바꿉니다(0x80000–0x100000은 EELOAD 영역 밖이 비어 있음). ziglang(clang/lld)으로 MIPS2 코드를 컴파일합니다.
5. **텍스처** `tools/kfont.py`: 원래 VRAM 크기를 유지하려고 8bpp 폰트를 4bpp로 바꿔(큰 폰트 256×256 8bpp → 512×256 4bpp) 위쪽에 라틴 글리프, 아래쪽에 캐시 칸을 둡니다. 큰 폰트 한글은 4bpp(칸 18×21), 작은 폰트는 1bpp(칸 12×14)로 실행파일에 저장합니다.
6. **버튼 아이콘**: 폰트 텍스처 안의 ×·△·○·□·L1/R1 아이콘은 색이 있어, 4bpp 16색 팔레트를 흰색 알파 9단계(글자) + 아이콘 7색(4색 기호 + k-means로 고른 무채색 3)으로 나눴습니다. 아이콘 칸은 색 픽셀로 찾아 가장 가까운 색으로 양자화합니다. 또 0x1a03f0의 아이콘 스캔 루프가 0xA2 바이트를 아이콘 문자로 잘못 해석하던 것을 0x1a042c 패치로 막았습니다.
7. **커닝**: FIF 폰트의 커닝 표가 한글 슬롯(0xF0–0xFE)에 적용되지 않도록 해당 항목을 0으로 둡니다.

## 텍스트

- `tools/extract_text.py`로 실행파일·데이터의 문자열을 중복 없이 뽑아 `translation/*_en.txt`로 만들고, 같은 줄 번호의 `*_ko.txt`로 바꿉니다.
- 게임 문자열 파일은 4개 언어 파일 모두를 같은 한국어로 바꿉니다.

## 그림 글자

`tools/menutex.py`: 메인 메뉴 항목(그라데이션 + 짙은 테두리 + 그림자)과 "돌아가기", 로딩 화면 "불러오는 중"을 원본 P2N 8bpp 팔레트 안에서 다시 그려 같은 크기로 제자리에 넣습니다.

## 동영상 자막

- SFD는 2048바이트 섹터마다 MPEG-1 팩 하나와 스트림 하나(영상 PES 2030바이트, 페이로드 2018바이트 / ADX·AC3 음성)로 이루어져 있습니다.
- `tools/movie_sub.py`: 영상 기본 스트림을 꺼내 PyAV로 디코드하고, 자막을 합성해 ffmpeg(mpeg2video)로 같은 프레임 수·같은 해상도로 다시 인코딩합니다. 비트레이트는 원래 영상 섹터 용량의 80%로 맞춥니다.
- `tools/sofdec_remux.py`: 음성 섹터·팩 헤더·SCR은 그대로 두고 영상 섹터의 페이로드만 새 스트림으로 채우며, 각 섹터의 PTS/DTS를 새 프레임 순서에 맞게 다시 계산합니다. 파일 크기가 원본과 같아 ISO의 같은 자리에 덮어씁니다.
- 영어 대사는 `tools/movie_asr.py`(faster-whisper medium)로 받아쓰고, 번역은 직접 했습니다.

## 테스트

`tools/emu.py`는 휴대용 PCSX2를 최소화 상태로 띄우고 PINE으로 세이브 스테이트를 만들어 화면·RAM을 얻습니다. `tools/vpad.py`는 테스트용 cheats pnach로 패드 읽기 함수에 가상 버튼을 OR 하는 코드를 넣어, PINE 메모리 쓰기로 버튼을 누릅니다(배포판에는 들어가지 않음).
